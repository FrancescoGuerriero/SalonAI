# Software bill of materials

SalonAI uses CycloneDX JSON SBOMs generated by Trivy.

## Generate SBOMs

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\security\generate-sbom.ps1" -ProjectRoot "."
```

The repository SBOM is always generated. Image SBOMs are generated for the local backend, frontend, and AI-service images when those images exist.

## Evidence

`security-reports/sbom/manifest.json` records each SBOM filename, size, and SHA-256 digest. Keep the manifest and SBOMs with the release evidence.

## Privacy

Production environment files, MongoDB backups, generated reports, Git metadata, dependency caches, and virtual environments are excluded from repository SBOM scanning.
